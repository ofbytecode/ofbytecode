### 📄 Система автоматизации формирования документации

Full-stack / Automation проект

Приложение для автоматизированного формирования официальных документов на основе стандартизированных шаблонов и данных из Excel. Сокращает ручную работу при подготовке большого количества однотипных документов и снижает риск ошибок при переносе данных.

**Процесс:**
`Excel/данные → Проверка → Шаблон → Генерация → Комплект документов → Реестр`

**Возможности:**
- загрузка структурированных данных из Excel
- стандартизированные шаблоны документов
- автоматическая подстановка данных
- пакетная генерация документов
- предварительная проверка входных данных
- автоматическое формирование реестров
- работа с версиями шаблонов
- централизованное управление данными
